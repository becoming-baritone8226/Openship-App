# Writing Plans Superpower

Create actionable, modular, and verifiable implementation plans.

## Guidelines for Plans

1. **Explicit Scope**: Clearly list what is in-scope and what is explicitly out-of-scope.
2. **File Level Diffs**: Break down changes by component and specify exact files being created, modified, or deleted.
3. **Dependencies First**: Order steps logically so lower-level models and clients are implemented before higher-level ViewModels and UI.
4. **Verification Criteria**: Every phase must contain automated and manual verification steps.
5. **Open Questions**: Surface design tradeoffs, potential breaking changes, or ambiguities upfront.
