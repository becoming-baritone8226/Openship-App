# Brainstorming Superpower

Guides architectural exploration and requirements discovery.

## Workflow

1. **Clarify Intent**: Ask clarifying questions to eliminate ambiguities and define product boundaries.
2. **Explore Options**: Present 2-3 viable technical approaches with tradeoffs (performance, complexity, maintenance).
3. **Align on Decisions**: Record locked decisions and constraints into documentation (`CONTEXT.md` / `README.md`).
4. **Draft Next Steps**: Formulate concrete, testable tasks.
